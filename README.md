# collinear-siddharthshashankkumar

Take-home submission for Collinear AI, by Siddharth Shashank Kumar. One Harbor task:

**[t20-exact-forecast](t20-exact-forecast/)**, in which an AI agent forecasts match win probabilities for a simulated Twenty20 cricket league and is graded against the exact truth of that league. The pass rule was committed before any model ran. Claude Opus 4.7 and GPT-5.5 failed it ten times out of ten, for one diagnosed cause; Claude Fable 5.1 and GPT-6-astra passed four of five completed runs.

Start with [t20-exact-forecast/README.md](t20-exact-forecast/README.md), then [DESIGN_DOCUMENT.md](t20-exact-forecast/DESIGN_DOCUMENT.md). The packaged task is at `t20-exact-forecast/dist/collinear-siddharthshashankkumar/t20-exact-forecast/`, and every run is recorded under `t20-exact-forecast/jobs/`.
